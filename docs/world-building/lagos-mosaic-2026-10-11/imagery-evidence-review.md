# Dated imagery evidence audit

Access and pixel-inspection date: **October 11, 2026**. Scope: existing Makoko/Ipakodo dossier and Old Lagos Island dossier. Five high-value reference entries, six original photographs inspected; no new neighborhood narrative or implementation. Existing dossiers and coordinator README remain unchanged.

## Method and evidence boundary

We read `AGENTS.md`, coordinator `README.md`, `lagoon-neighborhoods.md` and `old-lagos-island.md`; also searched `everyday-mainland.md` for imagery gaps and slice names. Fresh Wikimedia Commons API responses supplied description-page revisions, source/author/license fields, upload timestamps, camera `DateTimeOriginal`, dimensions and original-file SHA-1. These are repository records, not independently authenticated camera clocks. Capture timestamps below have **no established timezone**; upload/revision timestamps ending `Z` are UTC. Upload, edit and access dates do not date the pictured construction.

We opened a dedicated public-web preview tab, inspected its page state before subsequent interaction, navigated to each original `upload.wikimedia.org` JPEG, and viewed returned screenshot pixels with `preview_snapshot(includeImage=true, save=false)`. Viewport: 1280 x 800; originals were browser-fitted, not inspected pixel-for-pixel at full resolution. Image dimensions/load state were checked for five originals; the remaining water photograph had a loaded original-image page and visible snapshot. No original, thumbnail or screenshot was saved locally; no AI imagery used. Snapshot text truncation did not prevent the returned image from being inspected.

Labels: **F** = retrieved source record or directly visible feature, qualified by pictured location/date; **M** = map/topology or locality inference; **P** = authored implication, not a discovered real condition; **U** = unresolved. A file caption alone does not establish what its pixels show. Painted/rendered/wooden-looking surfaces below are visual descriptions, not laboratory material identification. No observation applies to all Makoko, Ipakodo, Old Island or their appearance on October 11, 2026.
