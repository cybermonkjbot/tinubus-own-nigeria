## Goal and continuation contract

Develop geographically continuous Lagos sectors, beginning with Oshodi Interchange and its approaches. Each continuation independently chooses an adjacent sector, researches it afresh, and supplies spatial/topographic, traffic, material, audio, NPC and weather designs, a categorized Developer Asset Checklist, and one localized fictional event.

Keep facts, historical observations, design parameters and unknowns distinct. Do not invent street names, business identities, building heights, road permissions or survey precision. Any unevidenced final placement stays withheld. Missing evidence does not prevent useful blueprint work, but it prevents claims of complete geographic or cultural verification.

Use gpt-6.1-sol explicitly for new delegated work where available, preserving the existing reasoning effort. Report unavailable models rather than substituting. This package creates no agent and resumes no worker.
